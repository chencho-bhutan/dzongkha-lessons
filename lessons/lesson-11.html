Function of སྔོན་འཇུག in Word Construction

You already know there are five letters that can act as a Ngonjug — a letter placed before the main letter of a word: ག, ད, བ, མ, འ. But here's the catch: not every one of these five letters can attach to any main letter you like.

Each one only works with a specific set of main letters — like a key that only fits certain locks. To help sort out which prefix goes with which main letter, Dzongkha groups main letters into four traditional "families." You don't need to worry about what the family names technically mean — just think of them as labels, the same way you might sort socks into drawers without the drawer labels meaning anything beyond "these go together."

Why This Matters

This is the answer to a very natural question: why does one word take བ while a similar-looking word takes འ instead? It's never random — each main letter belongs to a specific group, and that group determines which prefixes are allowed to attach to it. Once you recognize a main letter's group, you'll know instantly which prefixes it can legally take, instead of having to guess or memorize every single word from scratch.

A small note: one entry above (ག paired with གཞན) is listed the way it appeared in the source material, though the word's own structure suggests it may technically belong with a different main letter. Worth double-checking against a print reference if you have one.
